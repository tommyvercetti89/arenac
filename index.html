printf & scanf Format Belirteçleri

C dilinde tür uyumsuzluğu tanımsız davranışa (UB) veya bellek bozulmalarına yol açar. Aşağıdaki tabloda yaygın ve sinsi format belirteçleri listelenmiştir:

Belirteç Tip Örnek Kullanım Açıklama / Çıktı
%d / %i int printf("%d", -42); İşaretli 32-bit tamsayı (-42)
%u unsigned int printf("%u", -1); İşaretsiz tamsayı. Negatif verilirse 4294967295 (UINT_MAX) basar!
%x / %X unsigned int printf("0x%X", 255); Onaltılık (Hexadecimal) gösterim (0xFF)
%o unsigned int printf("%o", 8); Sekizli (Octal) taban gösterimi (10)
%f float / double printf("%.2f", 3.1415); Kayan noktalı sayı (printf otomatik double'a yükseltir)
%lf double scanf("%lf", &val); scanf için şarttır! %f verilirse 4 byte yazar, double bozulur.
%c char printf("%c", 65); Tek bir ASCII karakter (A)
%s char* printf("%s", "ArenaC"); Null-terminated string. Bellekte \0 görene dek okur.
%zu size_t printf("%zu", sizeof(int)); C99 Standart boyutu. sizeof sonucu için %d yerine %zu kullanılmalıdır!
%td ptrdiff_t printf("%td", p2 - p1); İki işaretçi (pointer) arasındaki eleman farkı için standart belirteç.
%p void* printf("%p", (void*)ptr); Hekzadesimal bellek adresi (örn. 0x7ffee4b2c890).

Dinamik Biçimlendirme & İleri Düzey Bayraklar

printf("%.*s", 3, "ArenaC");

Dinamik uzunluk: İlk argüman kaç karakter basılacağını belirler. Çıktı: Are

printf("%*d", 5, 42);

Dinamik genişlik: Sütun genişliğini değişkenden alır. Çıktı: 42

printf("%05d", 42);

Sıfırla doldurma: 5 haneye ulaşana kadar sola sıfır ekler. Çıktı: 00042

printf("C%n", &cnt);

%n sayacı: O ana kadar ekrana basılan karakter sayısını değişkene yazar (cnt = 1).

Sık Karşılaşılan Format Tuzakları:
  • scanf("%d", n); yerine scanf("%d", &n); yazılmalıdır. Adres operatörü & unutulursa bellek ihlali (Segfault) olur.
  • scanf(" %c", &ch); — Başındaki boşluk kritik! Boşluk konulmazsa önceki girdiden arta kalan \n (Enter) karakterini okur.
  • printf("%s", 'A'); — Tek tırnak karakterdir (int 65). String bekleyen %s 65 nolu adresi okumaya kalkışır ve çöker!
<stdio.h>

Standart Giriş / Çıkış

  • printf(...) / scanf(...): Konsol biçimli çıktı ve girdi alma.
  • snprintf(buf, size, fmt, ...): Güvenli biçimlendirme! sprintf yerine her zaman snprintf tercih edilir; tampon taşmasını (buffer overflow) önler.
  • puts(str): Dizgiyi ekrana basar ve otomatik sonuna yeni satır (\n) ekler.
  • getchar() / putchar(c): Standart girdiden tek karakter okur / ekrana tek karakter yazar.
  • sscanf(str, fmt, ...): Konsoldan değil, bir string içinden biçimli veri ayrıştırır.
<stdlib.h>

Dinamik Bellek & Genel Yardımcılar

  • malloc(size): Heap'ten size byte tahsis eder. Belleği temizlemez (içi rastgele çöp değerdir).
  • calloc(num, size): Heap'ten yer ayırır ve tüm bitleri sıfırlar (0x00).
  • realloc(ptr, new_size): Tahsis edilen bloğun boyutunu değiştirir. Gerekirse yeni adrese taşır.
  • free(ptr): Tahsis edilen belleği sisteme iade eder. *(İpucu: free(p); p = NULL; dangling pointer'ı önler)*.
  • qsort(base, n, size, cmp): Hızlı sıralama algoritması (O(N log N)). Karşılaştırma fonksiyonu pointer'ı alır.
  • bsearch(key, base, n, size, cmp): Sıralı dizide ikili arama (Binary search - O(log N)).
  • strtol(str, &end, base): String'i güvenle tamsayıya çevirir (10'luk, 16'lık taban desteğiyle atoi'den üstündür).
  • exit(status): Programı anında belirtilen çıkış koduyla sonlandırır (0 = başarılı).
<string.h>

Dizgi & Ham Bellek İşlemleri

  • strlen(str): Dizginin \0 sonlandırıcı hariç net karakter uzunluğu.
  • strcmp(s1, s2): İki stringi kıyaslar. Eşitse 0 döner! s1 < s2 ise negatif, s1 > s2 ise pozitif.
  • strncmp(s1, s2, n): İlk n karakteri güvenle kıyaslar.
  • memcpy(dest, src, n): n byte bellek kopyalar. Kaynak ve hedef bellek çakışmamalıdır!
  • memmove(dest, src, n): Bellek alanları birbiriyle çakışsa bile (overlapping) güvenle kopyalar.
  • memset(ptr, val, n): Bellek bloğunun tüm byte'larını val değeriyle doldurur (örn: memset(arr, 0, sizeof(arr))).
  • strchr(s, c) / strstr(haystack, needle): Karakter veya alt-string arar, bulduğu adresi döner.
<stdint.h> & <stdbool.h>

Modern Taşınabilir Tip Güvenliği

  • int8_t, int16_t, int32_t, int64_t: Kesin bit genişlikli işaretli tamsayılar.
  • uint8_t, uint16_t, uint32_t, uint64_t: Kesin bit genişlikli işaretsiz tamsayılar.
  • uintptr_t: Bir pointer adresini kayıpsız tutabilecek genişlikte işaretsiz tamsayı.
  • bool, true (1), false (0): C99 ile gelen standart mantıksal tip.

Pointer Operatör Kombinasyonları

C mülakatlarında ve ArenaC sorularında en sık karşılaşılan tuzak kombinasyonlar:

İfade Eşdeğeri Ne Yapar? (İşlem Sırası)
*p++ *(p++) Mevcut adresteki değeri alır, ardından pointer adresini bir sonraki elemana kaydırır.
(*p)++ (*p)++ Adresteki değeri okur, ardından adresteki sayıyı 1 artırır (pointer adresi değişmez).
++*p ++(*p) Adresteki sayıyı önce 1 artırır, ardından güncel değeri döndürür.
*++p *(++p) Önce pointer adresini kaydırır, ardından ulaştığı yeni adresteki değeri okur.

Dizi Adı (arr) ile &arr Farkı

int arr[5] = {10, 20, 30, 40, 50};
int *p1 = arr;        // p1 türü: int* (ilk elemanın adresi)
int (*p2)[5] = &arr;  // p2 türü: int (*)[5] (5 elemanlı dizinin işaretçisi)
arr + 1:

1 eleman ilerler (sizeof(int) = 4 byte). &arr[1] adresine gider.

(&arr) + 1:

Tüm dizi boyutu kadar zıplar (5 * 4 = 20 byte). Dizinin bittiği adrese işaret eder!

Struct Hizalaması (Memory Padding)

İşlemciler bellek okuma hızını maksimize etmek için verileri doğal sınırlarına hizalar:

struct Data {
    char c;     // 1 byte
    // [3 byte boşluk (PADDING) eklenir]
    int x;      // 4 byte (4'ün katı adreste olmalıdır)
    short s;    // 2 byte
    // [2 byte boşluk (PADDING) struct'ı 4'ün katına tamamlar]
};
// Toplam sizeof(struct Data) = 12 byte (1 + 4 + 2 = 7 DEĞİL!)
Bellek Bölgeleri Kuralı:
  • Stack: Yerel değişkenler. Fonksiyon bitince bellek otomatik uçar. Yerel değişken adresi fonksiyondan döndürülmemelidir!
  • Heap: malloc ile alınan bölge. free edilene kadar yaşar.
  • ROData (String Literalleri): char *s = "Merhaba"; ifadesinde string sabiti salt okunur bellektedir. s[0] = 'm'; yazmaya çalışmak çökme (Segfault) üretir!

Öncelik Operatörler Yön (Assoc.) Açıklama

2 ++ -- + - ! ~ * & sizeof (type) Sağdan Sola Tekil (Unary) operatörler, adres/değer alma, tip dönüşümü
3 * / % Soldan Sağa Çarpma, bölme, mod
4 + - Soldan Sağa Toplama, çıkarma
5 << >> Soldan Sağa Bit kaydırma (Shift)
6 < <= > >= Soldan Sağa İlişkisel karşılaştırmalar
7 == != Soldan Sağa Eşitlik kıyaslaması
8 - 10 & sonra ^ sonra | Soldan Sağa Bit düzeyinde VE, XOR, VEYA
11 - 12 && sonra || Soldan Sağa Mantıksal VE, VEYA (Kısa devre değerlendirmesi!)

Kısa Devre (Short-Circuit) Davranışı

if (a && ++b)

Eğer a == 0 ise, sağ taraf asla değerlendirilmez. b değeri artmaz!

if (a || ++b)

Eğer a != 0 ise, sağ taraf asla değerlendirilmez. b değeri artmaz!

Klasik Tuzaklar

  • *p.x → . önceliği *'dan yüksektir! Aslında *(p.x) olarak çalışır. Doğrusu: (*p).x veya p->x.
  • if (x & 1 == 0) → == önceliği &'den yüksektir! Aslında x & (1 == 0) hesaplanır. Doğrusu: (x & 1) == 0.
  • c = a, b; → Atama önceliği virgülden yüksektir! (c = a), b; olur (c = a). Ancak c = (a, b); yazılırsa c = b olur!
Tanımsız Davranış (Undefined Behavior - UB):
  • i = i++ + 1; veya printf("%d %d", i++, i++); → Aynı sequence point içinde aynı değişkeni birden fazla kez değiştirmek UB'dir!
  • INT_MAX + 1 → İşaretli tamsayı taşması C standardına göre tanımsızdır (UB). (İşaretsiz UINT_MAX + 1 ise modulo 2^32 ile tanımlıdır).
  • Başlatılmamış yerel değişkeni okumak (int x; printf("%d", x);).
  • Sıfıra bölme (x / 0).
  • Dizi sınırları dışına taşma (Buffer Overflow).
